# Silhouette Studio 5.0 Feature Checklist

Source: [Silhouette Studio 5.0 User's Manual](manual.txt). Items follow the manual's numbered chapters and section names. Each named tool, menu command, panel option, or feature has one unchecked entry; edition restrictions are noted where documented.

## 01 — General Information

### Features Overview

- [ ] **File import** — Import a variety of vector and raster file formats.
- [ ] **Print & Cut** — Print designs and cut around them using registration marks; requires a printer.
- [ ] **Design Store downloads** — Download exclusive digital content.
- [ ] **Library organization** — Organize and optimize the library image collection.
- [ ] **Installed font cutting** — Cut font files already installed on the computer.
- [ ] **Word and letter wrapping** — Wrap text within a text box.
- [ ] **Text justification** — Control text alignment and justification.
- [ ] **Character spacing** — Adjust spacing between letters.
- [ ] **Text to Path** — Fit text to a line or shape path.
- [ ] **Line drawing** — Draw straight lines.
- [ ] **Basic shape drawing** — Draw circles, squares, and rounded rectangles.
- [ ] **Polygon and curved-line drawing** — Draw polygons and curved lines.
- [ ] **Freehand drawing** — Draw continuous free-form lines.
- [ ] **Exact image resizing** — Resize images to exact specifications.
- [ ] **Group/Ungroup** — Group or ungroup sets of lines for manipulation.
- [ ] **Point editing** — Edit and manipulate points of text and images.
- [ ] **Freehand eraser** — Erase parts of an image.
- [ ] **Weld** — Join overlapping images and remove internal overlapping lines.
- [ ] **Shadowed mat effects** — Create offset outlines and shadowed mats.
- [ ] **Transform** — Move, rotate, scale, and otherwise transform images.
- [ ] **Align** — Align and distribute images.
- [ ] **Replicate** — Create arranged copies of images.
- [ ] **Modify** — Apply Boolean-style operations to overlapping images.
- [ ] **Line types** — Manipulate line types for different cutting actions.
- [ ] **Custom color fills** — Fill images with custom colors.
- [ ] **Gradient fills** — Fill images with gradients.
- [ ] **Pattern fills** — Fill images with patterns.
- [ ] **Undo/Redo** — Reverse and reapply an unlimited number of actions.

### Software File Formats

- [ ] **DXF opening** — Open supported DXF vector data in ready-to-cut form.
- [ ] **SVG opening (paid option)** — Open SVG vector data in ready-to-cut form.
- [ ] **Raster image import** — Import JPG, BMP, PNG, TIFF, GIF, and WMF images for printing or tracing.
- [ ] **PDF import (paid option)** — Import PDF files for printing or tracing.
- [ ] **Installed font access** — Access fonts installed on the computer without installing them into Studio.

### Available Digital Content

- [ ] **Silhouette Design Store access** — Browse and purchase additional designs and fonts from within the software.
